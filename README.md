# Kabe Miller

**AI systems architect. Twenty-three years of walking into unfamiliar systems and imposing reliable order, now doing it for agentic AI.**

I ran [Cornerstone Computers](https://cstonecomputers.com) for twenty-three years: founder, CEO, and by choice the principal technician on every commercial engagement, from dental imaging to water-treatment plants, across undocumented and archaic systems under emergency conditions. That practice trained one instinct above all: **detecting silent failure**, the system that looks operational while degrading underneath. It is the most dangerous failure mode in physical infrastructure, and it is the most dangerous failure mode in agentic AI.

Everything here is one research arc, built spec-first with Claude Code implementing under my direction. The commit history shows that collaboration openly.

## The arc

| | |
|---|---|
| **[Kernos](https://github.com/5000Stadia/Kernos)** | An agentic OS that treats memory, safety, honesty, and self-maintenance as *infrastructure* rather than prompt text. Cohort architecture, event-sourced dual memory, kernel-level dispatch gates. v1.0 research-complete; 17 published design principles. |
| **[pattern-buffer](https://github.com/5000Stadia/pattern-buffer)** | A **platform-neutral world-tracking engine**: one append-only assertion log; state, knowledge, and history as disposable projections. Real-world tracking for business-class agents and interactive fiction are the same machine under one policy switch. |
| **[Construct Projector](https://github.com/5000Stadia/construct)** | The showcase: an interactive-fiction engine where the world's truth is a database and the model is only a voice. Spoilers and NPC secrets are *structurally absent* from context windows, never merely forbidden. |
| **[AgentPost](https://github.com/5000Stadia/agentpost)** | A durable local post office for concurrently running agents. Persistent CLI-neutral identities, Markdown mailboxes, idle or immediate delivery. Waiting and scheduling are algorithmic and token-free, so model usage begins only when an agent actually processes mail. |
| **[AgentBridge](https://github.com/5000Stadia/agentbridge)** | A documented working structure for a project run by one human and a small number of agent seats. The human decides; one seat holds the chart and never the wheel; one builds; one falsifies both the work and whether it is still the right work. The reviewer never receives the builder's private reading of the intention, which is what makes its judgment independent. |

**The through-line:** agents can't reliably self-enforce constraints or self-maintain memory , so the substrate must. The agent thinks; the kernel remembers, notices, routes, and protects.
